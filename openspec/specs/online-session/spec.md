## Purpose

提供企业级在线会话感知监控、实时心跳与管理员强制下线（Force Logout）安全阻断服务，保障系统会话安全与合规审计闭环。

## Requirements

### Requirement: 登录会话自动登记与 Redis 存储
系统 SHALL 在员工成功登录（密码登录或 SSO 登录）后，自动收集客户端环境信息并在 Redis 中建立活动会话，生命周期与 JWT 保持一致。

#### Scenario: 成功记录在线会话
- **WHEN** 员工在管理后台登录成功
- **THEN** 系统生成会话唯一 ID，将员工账号、IP、浏览器、操作系统及登录时间存入 Redis 有序集合与会话键

### Requirement: 在线用户列表分页与条件检索
系统 SHALL 支持管理员按账号、IP 地址等条件分页检索当前所有在线员工会话。

#### Scenario: 查询在线员工
- **WHEN** 管理员打开“在线用户”监控页面
- **THEN** 系统返回当前全部活跃未过期会话总数与分页列表，自动剔除已自然过期的过期项

### Requirement: 会话强制下线 (Force Logout) 与黑名单即时拦截
系统 SHALL 支持管理员将任意目标会话即时强退，被强退会话的 Token 将立即失效，后续所有请求被拦截。

#### Scenario: 成功强制下线他人会话
- **WHEN** 管理员点击某在线用户的“强退”按钮并确认
- **THEN** 系统将该会话的 Token Hash 记入 Redis 黑名单，并清除在线会话；该用户后续调用接口立即返回 401 并退出到登录页

#### Scenario: 超管自身会话防误操作保护
- **WHEN** 列表展示当前操作人自己的会话条目
- **THEN** 操作列“强退”按钮呈现禁用态，并提示“不可强退当前登录会话”
