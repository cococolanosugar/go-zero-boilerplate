# Proposal: 企业全站防截屏安全水印系统 (Security Watermark Protection)

## 1. 背景与动机
在中大型企业运营与内部管理系统（如 LinaPro、Ruoyi Admin）中，防止敏感数据（客户隐私、财务数据、员工名单、业务订单）通过物理屏幕截屏、手机拍照等方式恶意泄露是安全合规审查的核心指标之一。

为保证数据外泄后能够精准追踪溯源到具体泄露人，本优化实施企业级全站动态防截屏安全水印：
1. **多行水印画像标识**：包含当前登录员工真实姓名、账号唯一标识、系统全称以及“内部机密 严禁外传”法律威慑标语；
2. **主题自适应与视觉美感**：根据系统当前亮色/暗色主题自适应调节透明度与颜色（深色模式 `rgba(255, 255, 255, 0.07)`，浅色模式 `rgba(0, 0, 0, 0.07)`），在不影响日常表格与表单可读性的前提下实现 100% 页面视口覆盖；
3. **设置抽屉开关与会话持久化**：在 `SettingDrawer` 中集成水印开关与实时切换，并联动 `LayoutSettingsContext` 与 `SafeStorage` 进行多标签页跨端广播同步。

## 2. 方案与交付物
1. **`app.tsx` / `BasicLayout.tsx` 水印引擎扩展**：
   - 升级 `waterMarkProps` 为结构化双行安全水印，自适应亮暗色主题；
   - 在 `SettingDrawer` footer 区域提供直观的“全站防截屏水印”与“多标签页导航”快捷配置 Switch。
2. **前端单元测试保障**：
   - 编写 `frontend/apps/admin/tests/watermark.test.ts` 验证水印文本组装、主题颜色切换与配置持久化；
   - 运行 `just lint-antd` 与 `just test-frontend` 确保 100% 验收。
3. **真实浏览器验证**：
   - 使用 Chrome DevTools 验证水印渲染、开关切换与抽屉控制效果并留存截图归档。
