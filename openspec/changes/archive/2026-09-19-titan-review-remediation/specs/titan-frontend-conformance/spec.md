## Purpose

约束 Titan 前端应用（`@zero/titan` 及 admin 内嵌 Titan 页面）的用户可感知行为：语言切换真实生效、组件库 API 合规、列表数据不竞态、表单不丢数据、操作结果必有反馈。

## ADDED Requirements

### Requirement: i18n 语言切换生效
Titan 前端全部用户可见文案（页面内容、表单标签、按钮、提示消息、导航菜单）SHALL 经由 i18n 资源文件渲染，切换语言后界面 SHALL 整体切换为目标语言。三语资源文件（zh-CN、zh-TW、en-US）SHALL 保持 key 完整对齐。SHALL NOT 存在硬编码的目标语言文案绕过 i18n。

#### Scenario: 切换到英文整体生效
- **WHEN** 用户将语言切换为 English
- **THEN** 页面内容、表单标签、操作提示与导航菜单均显示英文

#### Scenario: 导航菜单走路由元数据
- **WHEN** 语言切换后查看侧边导航
- **THEN** 菜单文案由路由配置的国际化元数据驱动，与页面语言一致

### Requirement: 组件库 API 合规
Titan 前端 SHALL 不使用所在组件库（Ant Design 6）已废弃的 API；项目的组件库静态检查命令 SHALL 对 Titan 相关目录零警告零废弃项通过。

#### Scenario: 静态检查零告警
- **WHEN** 对 Titan 前端目录运行项目规定的组件库 lint 命令
- **THEN** 检查通过，无废弃 API 使用警告

### Requirement: 列表数据竞态保护
带上下文切换的列表与看板数据加载 SHALL 具备竞态保护：上下文（项目、环境、应用）切换后到达的过期响应 SHALL NOT 覆盖当前上下文的数据展示。

#### Scenario: 快速切换项目数据一致
- **WHEN** 用户快速连续切换项目 A、B
- **THEN** 页面最终展示项目 B 的数据，A 的迟到响应被丢弃

#### Scenario: 切换项目不重复拉取项目列表
- **WHEN** 用户在已加载项目列表后切换当前选中项目
- **THEN** 不触发全量项目列表的重复请求

### Requirement: 表单数据完整性
编辑弹窗提交时 SHALL 完整保留资源的全部字段值：已加载到表单但未展示给用户的字段 SHALL 随提交原样保留，SHALL NOT 因表单未注册字段而被静默清空。

#### Scenario: 编辑应用不丢集成绑定
- **WHEN** 用户编辑应用并保存（表单中未展示集成绑定字段）
- **THEN** 应用原有的集成绑定保持不变

### Requirement: 操作结果用户反馈
所有写操作（创建、更新、删除、部署、保存）的结果 SHALL 有用户可见反馈：成功有成功提示；失败有明确错误提示；SHALL NOT 出现操作失败静默无提示或被吞掉的情况。

#### Scenario: 保存失败有提示
- **WHEN** 流水线设计器保存因网络或服务端错误失败
- **THEN** 用户看到明确的失败提示，可重试

#### Scenario: 列表加载失败有提示
- **WHEN** 列表数据加载失败
- **THEN** 用户看到错误提示或空态说明，而非无反馈空白

### Requirement: 表单格式校验
含结构化内容的表单字段 SHALL 提交前校验格式：JSON 字段校验可解析性、YAML 字段校验基本语法、Kubernetes 命名空间字段校验 DNS-1123 格式、URL 字段校验 URL 格式；校验失败 SHALL 在表单内提示且阻止提交。

#### Scenario: 非法 JSON 阻止提交
- **WHEN** 用户在构建配置字段输入非法 JSON 并提交
- **THEN** 表单内提示 JSON 格式错误，提交被阻止

#### Scenario: 非法命名空间阻止提交
- **WHEN** 用户在环境表单的命名空间字段输入含大写字母或下划线的值
- **THEN** 表单提示命名空间格式要求，提交被阻止

### Requirement: 轮询体验无闪烁
执行详情等轮询页面在轮询刷新时 SHALL 保持已渲染内容可见（静默刷新），SHALL NOT 每次轮询触发整页加载态闪烁。

#### Scenario: 轮询期间页面稳定
- **WHEN** 执行详情页处于进行中状态并每数秒自动刷新
- **THEN** 页面内容持续可见，无整页加载态反复闪烁
