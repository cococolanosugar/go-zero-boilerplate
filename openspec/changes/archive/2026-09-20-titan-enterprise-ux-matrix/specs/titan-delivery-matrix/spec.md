## Purpose

提供环境-微服务二维交付全景矩阵看板能力，实现多环境多微服务运行状态横向对比、实时副本健康指示、一键环境晋级发布与配置版本 Diff。

## ADDED Requirements

### Requirement: 环境-微服务二维矩阵大盘
交付控制台 SHALL 提供二维全景矩阵看板视图：纵轴列出当前项目下的全部微服务组件，横轴列出当前项目关联的全部交付环境（DEV、TEST、STAGING、PROD 等）。

#### Scenario: 打开交付矩阵看板
- **WHEN** 用户进入环境交付中心并切换至全景矩阵视图
- **THEN** 界面渲染以微服务为行、以环境为列的二维网格，各交叉单元格展示对应环境该服务的运行态

### Requirement: 单元格微状态与版本指示
矩阵各单元格 SHALL 紧凑展示当前运行的镜像版本 Tag、最后部署时间，并通过呼吸灯微状态圆点展示 Pod 就绪副本数与期望副本数（如 `2/2`）；未部署时显示空态与快捷部署入口。

#### Scenario: 单元格运行态展示
- **WHEN** 某应用在目标环境已部署且 Pod 就绪
- **THEN** 单元格显示绿色健康呼吸灯、镜像版本号（如 `v1.2.4`）、副本比例（`2/2`）以及最近更新时间

#### Scenario: 单元格未部署状态
- **WHEN** 某应用在目标环境尚未建立部署绑定
- **THEN** 单元格显示灰色虚线空态与“去部署”快捷动作

### Requirement: 跨环境一键晋级与版本对比
矩阵视图 SHALL 支持直接在单元格间进行横向版本比对（YAML Diff / Git Commit Diff），并支持将上一环境验证通过的制品一键晋级部署至下一目标环境。

#### Scenario: 一键将测试环境版本晋级至预发环境
- **WHEN** 研发负责人点击微服务在预发单元格的“从测试环境晋级”操作
- **THEN** 系统自动填入测试环境当前验证成功的制品信息，弹出确认抽屉，提交后下发至预发环境

#### Scenario: 跨环境部署配置 Diff
- **WHEN** 用户点击对比某应用在开发与生产环境的部署差异
- **THEN** 系统展示两套环境当前部署 YAML 与镜像 Digest 的可视化 Diff 对比视窗
